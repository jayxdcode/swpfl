    About swpfl

    swpfl

    Spotify Web Player Floating Lyrics

    What It Does

    swpfl adds a floating, draggable lyrics panel to Spotify Web Player in Firefox.

    • Real-time synced lyrics
    • Resizable & movable interface
    • Opacity control
    • Lyrics from LRCLib
    • Translations & romanization via Google AI

    Technical Info

    • Platform: Firefox Desktop & Firefox Android
    • Status: Experimental
